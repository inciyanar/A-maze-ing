## Why MIT?

This project includes a reusable `mazegen` package (the `MazeGenerator`-style
`Maze` class in `maze_ing.py`) that is explicitly meant to be imported and
built upon by later, separate projects. MIT was chosen because it imposes the
fewest restrictions on reuse: any later project — school assignment,
personal, or commercial — is free to import, modify, and redistribute this
code (including as part of a larger, differently-licensed work), as long as
the original copyright notice is kept. This directly satisfies the
requirement that the license "explicitly allow the reuse and distribution of
your maze generator by the later project(s) that build on it."
